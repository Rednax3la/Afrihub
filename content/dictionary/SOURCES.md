## Reuse boundaries

[Wiktionary text terms](https://en.wiktionary.org/wiki/Wiktionary:Copyrights) and [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) permit reuse subject to attribution and share-alike obligations. Selected lexical text is adapted from Wiktionary contributors via [Kaikki/Wiktextract](https://kaikki.org/dictionary/rawdata.html); include entry/history links, source credit, licence link and a modification notice. The import keeps that metadata and the UI displays it. Treat the adapted dictionary data as CC-BY-SA; do not claim proprietary exclusivity over it. Media, quotations/examples and other externally sourced material can have separate rights, so this adapter excludes them. No voice/audio rights are inferred from text permission.

The source is community-edited and machine-extracted, not tutor-verified. POS, multiple glosses and tags remain attached to individual senses. ?Unspecified? dialect means exactly that; a broad language label is not proof of the course?s intended variety. No AI-generated translations are collected here. Postprocessed per-language Kaikki downloads are deprecated upstream: replace the adapter with an approved raw-data workflow if withdrawn; do not scrape around a failure.

Lughayangu is a permission-request candidate, not a free dataset; its public pages do not establish commercial export rights. Glosbe combines sources with different provenance; no bulk licence is assumed. The Asante Twi repository explicitly has GPL-3.0; it is a promising separately licensed candidate, but not mixed into the CC-BY-SA import without a distribution-compliance review. The Meru endpoint and Igbo API data terms need confirmation; a code licence alone is insufficient. No access controls were bypassed and no unlicensed dictionary was scraped.

## Repeatable collection and publication

1. Run `python backend/scripts/collect_dictionary.py`. It checks robots.txt, uses official download URLs only, waits at least two seconds between new downloads, caps each source at 150 MB, caches completed source files, and writes output atomically. Rerunning resumes at completed sources and deterministically deduplicates senses; an incomplete source restarts its download. Retain snapshot/checksum metadata. Do not silently refresh a production dataset from a moving upstream URL.
2. Run `python backend/scripts/import_dictionary.py data/dictionary` for a local dry run; it does not load credentials or connect to a database. Validation rejects unknown languages, missing provenance and unreviewed publication.
3. After infrastructure recovery, from a trusted operator environment with explicit backend `MONGODB_URI` and existing `DB_NAME`, run the same command with `--apply`. This creates search indexes and imports **drafts only**. Repeated imports preserve existing reviewed edits. This step was not run.
4. A qualified reviewer must inspect native/English mapping, sense, spelling/diacritics, dialect, appropriateness and rights. Put a curated subset in a separate JSONL directory, retain stable `_id` and source notices, set `review_status=reviewed`, `status=published`, `reviewed_by` and `reviewed_at`. Dry-run with `--publish-reviewed`; only then repeat with `--publish-reviewed --apply`. That explicit mode can update those reviewed entries. No auto-approval or automatic deletion is provided.
5. Check the server-side search and visible attribution. Imported entries use indexed normalized **prefix** search (native or English gloss), with a 20-result default, 100 maximum and two-second database execution bounds. Diacritics are preserved; ASCII-only typing is not silently treated as equivalent. Multiple meanings can appear separately.

## Existing lessons

Quiz `prompt` is the native expression; its correct option is English. In generated quiz questions `native_text` is pronunciation, while reading/flashcard `native_text` is English. The compatibility adapter checks options first and never searches the pronunciation as an English translation. Existing published lesson entries remain available independently of dictionary imports. That legacy aggregation remains a bounded fallback (200 candidate rows / two-second budget), not a fully indexed standalone lexicon. A future reviewed materialization job can replace that scan; this change does not copy or auto-approve generated lesson vocabulary.
